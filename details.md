# Cloak (`cloak`) — Comprehensive Project Specification & Architecture

## 1. Executive Summary

**Cloak** is an open-source, local-first developer privacy CLI and proxy. It acts as an automatic privacy shield between a developer’s terminal, clipboard, code editors, and third-party Large Language Models (LLMs) such as Claude, ChatGPT, Copilot, Antigravity, and Gemini.

Cloak intercepts raw terminal errors, stack traces, and server log dumps, deterministically masks sensitive production credentials (API keys, JWTs, database connection strings, private IPs, emails, customer UUIDs) into syntactically valid synthetic placeholders, and enables reverse rehydration so suggested fixes generated by the AI can seamlessly translate back to the user's real local environment.

---

## 2. Problem Statement

### 2.1 The Vulnerability in Daily Developer Workflows
When developers face unexpected crashes or system errors, the universal instinct is to copy the terminal output or log snippet and paste it into an AI assistant (via web apps, IDE extensions, or copilot chat windows).

These raw logs frequently contain sensitive data:
- **Cloud & SaaS Credentials:** AWS Access Keys (`AKIA...`), GitHub personal access tokens (`ghp_...`), Stripe secret keys, OAuth Bearer tokens, JWT payloads.
- **Infrastructure Topologies:** Internal Kubernetes cluster IPs (`10.x.x.x`, `192.168.x.x`), private AWS RDS endpoints (`*.rds.amazonaws.com`), custom hostnames, port allocations.
- **Personally Identifiable Information (PII):** Customer emails, user IDs, session cookies, database connection strings with embedded passwords.

Pasting this directly into LLM chats leaks mission-critical company infrastructure and proprietary data to third-party model providers.

### 2.2 Why Simple Redaction (`[REDACTED]`) Fails
Existing redactors replace sensitive strings with generic tags like `[REDACTED]` or `***`. This creates severe downstream failures:
1. **Breaks Syntax & Parsing:** In JSON logs or structured headers, replacing a value with `[REDACTED]` often breaks JSON/YAML parser specifications or syntax highlighters.
2. **Loss of Correlation & AI Hallucination:** If 5 distinct worker nodes or 3 distinct user IDs are all converted to `[REDACTED]`, the LLM cannot discern relationships. It cannot detect that "Node A crashed due to a timeout while Node B stayed healthy", leading to inaccurate debugging advice.
3. **Broken Re-usability:** If the AI outputs a debugging command like `psql -h [REDACTED] -U [REDACTED]`, the command is completely unusable without tedious manual variable replacement by the developer.

## 3. The Solution: Cloak Architecture

Cloak solves this with a **three-step local privacy pipeline**:

```
[ Developer Terminal / Clipboard ]
                │
                ▼ (Raw logs with secrets)
     ┌──────────────────────┐
     │      `cloak`         │
     │ 1. Format Sniff      │ ───▶ [ Local Session Vault ]
     │ 2. Regex / Pattern   │      (Encrypted SQLite / In-Memory)
     │ 3. Deterministic Mock│      { real_secret ⟷ synthetic_mock }
     └──────────────────────┘
                │
                ▼ (Clean logs with valid synthetic mocks)
   [ AI Chat / Gemma 4 / Claude / ChatGPT ]
                │
                ▼ (AI fixes with synthetic values)
     ┌──────────────────────┐
     │  `cloak restore`     │ ◀─── [ Local Session Vault ]
     │ (Reverse Rehydration)│
     └──────────────────────┘
                │
                ▼ (Usable commands & fixes with real local hosts/IDs)
[ Ready to execute in local terminal ]
```

### 3.1 Three Core Pillars

1. **Deterministic Semantic Mocking:**
   Instead of `[REDACTED]`, Cloak replaces data with structurally identical, valid synthetic mocks:
   - `user_piuli_92@gmail.com` $\rightarrow$ `dev_usr_01@example.com`
   - `192.168.1.104:5432` $\rightarrow$ `10.0.0.101:5432`
   - `prod-db-cluster.us-east-1.rds.amazonaws.com` $\rightarrow$ `mock-db-host.internal`
   - `AKIA3XF8BGHJ72KDS9F1` $\rightarrow$ `AKIA0000EXAMPLE0001`
   - *Determinism Guarantee:* If `prod-db-cluster` appears 18 times across 400 lines, it consistently maps to `mock-db-host.internal` every single time.

2. **Local Session Vault (Zero Cloud Leakage):**
   The mapping table between real secrets and synthetic mocks is strictly ephemeral and stays on the local machine (`~/.cloak/sessions.db` or memory). It never touches the network and automatically prunes after 60 minutes.

3. **Two-Way Rehydration:**
   When an AI responds with suggested code or CLI commands referencing the synthetic values, `cloak restore` reads the AI response, performs a reverse lookup in the local vault, and restores the real environment identifiers so commands can be executed immediately.

## 4. User Interaction Models

### Model 1: Clipboard Bridge (Primary Developer Workflow — 90% use case)
Fits naturally into standard developer habits:
1. Error appears in VS Code / Terminal $\rightarrow$ Select & `Ctrl+C`.
2. Developer runs:
   ```bash
   cloak clip
   ```
   *Cloak reads clipboard, sanitizes in <10ms, prints a summary report, and overwrites clipboard with the safe content.*
3. Paste (`Ctrl+V`) into ChatGPT, Claude, Copilot, or Antigravity chat.
4. AI provides a code fix. Developer copies the AI message $\rightarrow$ runs:
   ```bash
   cloak restore
   ```
   *Clipboard is restored with real endpoints, ready to apply.*

### Model 2: Headless Unix Pipe
```bash
# Sanitize and write to stdout or copy to clipboard
cat crash.log | cloak
cat crash.log | cloak --copy

# Live log stream scrubbing
docker logs -f backend-service | cloak
```

### Model 3: Direct AI Query (`cloak ask`)
Integrates directly with **Gemma 4** open-weights model via Gemini API:
```bash
docker logs api-gateway | cloak ask "Why is this connection pooling error occurring?"
```
*Cloak sanitizes the piped log, passes clean tokens to Gemma 4, receives the solution, automatically rehydrates it locally, and prints the executable fix to terminal.*

### Model 4: Companion Local Web UI (`cloak ui`)
Spins up a lightweight local dashboard on `http://localhost:3000` featuring:
- **Left Pane:** Raw input text area.
- **Middle Pane:** Real-time Diff Viewer (Red = detected secret, Green = cloaked mock).
- **Right Pane:** AI chat with toggle: "View Cloaked AI View" vs "View Rehydrated Local View".

## 5. Internal Engineering Architecture

Cloak is partitioned into isolated, decoupled modules following strict single-responsibility principles:

```
cloak/
├── packages/
│   ├── core/                        # Pure business logic (Zero I/O dependencies)
│   │   ├── src/
│   │   │   ├── sniffer.ts           # Format detector (JSON vs Stacktrace vs Env/KV)
│   │   │   ├── patterns.ts          # Regular expressions & boundary token rules
│   │   │   ├── replacer.ts          # Deterministic mock generators (@faker-js/counter)
│   │   │   ├── vault.ts             # Session KV storage (bidirectional mappings)
│   │   │   ├── sanitizer.ts         # Main forward masking pipeline
│   │   │   ├── rehydrator.ts        # Reverse substitution engine
│   │   │   └── types.ts             # Strongly typed domain models
│   │   └── tests/                   # Comprehensive unit tests
│   ├── cli/                         # Terminal adapter
│   │   ├── src/
│   │   │   ├── index.ts             # Commander CLI entrypoint
│   │   │   ├── commands/            # clip, restore, ask, ui, pipe handlers
│   │   │   ├── ui/                  # Chalk, Boxen, ASCII art & table formatters
│   │   │   ├── clipboard.ts         # Native clipboard bridge
│   │   │   └── ai.ts                # Gemma 4 SDK client (Gemini API)
│   └── web/                         # Local companion playground (Vite + React)
│       └── src/
│           ├── components/          # DiffViewer, SessionInspector, ChatBox
│           └── App.tsx
```

### 5.1 Format-Aware AST & Sniffer Module
- **JSON Sniffer:** Detects JSON payloads. Parses strings into an Object tree, scrubs leaf string values, and serializes back. Guarantees 100% syntactically valid JSON output.
- **Stack Trace Sniffer:** Detects stack frames (e.g. `at Object.<anonymous> (/app/src/index.ts:42:15)`). Whitelists code paths and line numbers so AI debugging precision is not degraded, redacting only private username directories (`/Users/alice/...` $\rightarrow$ `/Users/dev/...`).
- **Authorization / Headers Sniffer:** Detects `Bearer <token>` or `Basic <token>` and isolates only the secret token parameter, leaving headers and verbs intact.

### 5.2 Deterministic Mocking Engine
Maintains an internal state machine per session:
```ts
interface SessionVault {
  sessionId: string;
  createdAt: number;
  realToMock: Map<string, MockEntity>;
  mockToReal: Map<string, string>;
}
```
When an entity (e.g., `user@domain.com`) is encountered:
1. Lookup in `realToMock`. If exists, return existing `mockValue`.
2. If new, generate next deterministic mock for category (e.g., `dev_user_01@example.com`).
3. Store both directions atomically.

### 5.3 Collision Prevention in Rehydration
To avoid accidental replacement of standard words in AI prose:
- Mock tokens use high-entropy semantic prefixes (e.g. `mock-db-host.internal`, `dev_usr_01@sandbox.local`, `<CLOAK_JWT_1>`).
- Rehydration performs boundary-checked keyword scans to guarantee only intentionally generated tokens are swapped.

## 7. Edge Cases & Defensive Safeguards

1. **Over-Matching Regex Prevention:**
   Standard ports or line numbers (e.g. `localhost:3000` or `line 404`) must not be identified as IDs or IPs. Regular expressions enforce strict token boundaries (`\b`) and require signature prefixes.
2. **Large Buffer Latency:**
   Log buffers can be megabytes in size. Regex parsing runs in linear time ($O(N)$) with compiled regex instances and stream chunks, keeping latency under 15ms for typical terminal buffers.
3. **Zero Data Retention:**
   Sessions auto-expire after 60 minutes. A manual command (`cloak clear`) purges all cached mappings immediately. Real secrets are never written to disk unencrypted.
